Privacy Policy for YouTube Mini Player Extension

Effective Date: February, 4, 2025

1. Introduction

Thank you for using the YouTube Mini Player extension. Your privacy is important to us, and we are committed to protecting any information you may provide while using this extension. This Privacy Policy explains what data the extension collects, how it is used, and your rights regarding your information.

2. Data Collection and Usage

This extension does not collect, store, or share any personal data. The only data accessed is related to the active YouTube tab to provide mini-player functionality. This includes:

  • Extracting the current YouTube video URL and title to display in the mini-player.
  • Using scripting permissions to create an overlay player within your browser.

All interactions happen locally within your browser, and no data is transmitted to external servers.

3. Permissions Justification

The extension requires certain Chrome permissions to function properly:

  • ActiveTab & Host Permissions (`https://www.youtube.com/`) – Needed to detect and extract the currently playing YouTube video.
  • Scripting API – Allows the extension to insert the mini-player functionality onto YouTube pages.
  • Storage (if applicable) – Only used to store user preferences (e.g., mini-player size, position) locally.

This extension does not collect browsing history, user activity outside of YouTube, or any personally identifiable information.

4. Third-Party Services

This extension does not use third-party analytics, tracking services, or advertising networks.

5. Data Security

Since no data is collected or transmitted, there is no risk of unauthorized access or data breaches. The extension only runs when manually activated by the user and does not store data persistently.

6. User Control & Consent

Because no user data is collected, no explicit consent is required. However, users can uninstall the extension at any time through the Chrome Extensions settings if they no longer wish to use it.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be reflected in the extension listing and on our official website.
